# Política de segurança e dados

## Relato responsável

Não abra uma issue pública com credenciais, dados pessoais ou detalhes exploráveis. Use o recurso
**Report a vulnerability** da aba Security do GitHub. Se ele não estiver disponível, abra uma issue
sem detalhes sensíveis solicitando um canal privado.

## Escopo de suporte

A versão mais recente da branch `main` recebe correções. O projeto é educacional, usa dados
agregados e cadastrais públicos e não deve receber dados individuais de pacientes.

## Segredos e dados

- não inclua tokens ou chaves no repositório;
- não substitua o snapshot por bases contendo CPF, CNS ou outros identificadores pessoais;
- revise licenças e termos antes de adicionar fontes;
- resultados do painel não devem ser usados isoladamente para alocação assistencial.
