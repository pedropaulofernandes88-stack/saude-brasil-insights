# Roadmap do portfólio — IA, saúde e dados

Este arquivo registra a sequência combinada para o portfólio.

| Ordem | Projeto | Competências principais | Status |
|---:|---|---|---|
| 1 | Saúde Brasil Insights | dados públicos, ETL, geoespacial, dashboard | **MVP concluído** |
| 2 | FHIR Patient Platform | interoperabilidade, APIs, PostgreSQL, FHIR | Planejado |
| 3 | ICU Risk Lab | ML clínico, calibração, equidade, MLOps | Planejado |
| 4 | Clinical RAG Eval | RAG, avaliação, citações, segurança | Planejado |

Critério para avançar: o projeto atual deve possuir documentação, execução reproduzível, testes e
uma demonstração revisada. Após a revisão final do Projeto 01, o próximo será o FHIR Patient
Platform.
